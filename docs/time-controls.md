# 대국 시간

- 일반: 각 진영 생각시간 10분, 소진 후 매 수 초읽기 30초.
- 속기: 각 진영 생각시간 3분, 소진 후 매 수 초읽기 10초.
- 초읽기는 시간을 더하는 increment가 아니다. 수를 두면 다음 차례의 초읽기가 초기화되며 누적되지 않는다.
- 생각시간이 수 도중 소진되면 바로 초읽기로 넘어간다. 초읽기까지 모두 소진한 시각부터 시간패다.
- 로컬 대국은 포진 확정 후 시작하고, 이동 연출과 둬보기 동안 정지한다. 둬보기 복귀 시 남은 초읽기를 보존한다.
- 온라인은 서버 시각을 기준으로 판정하며, 둬보기·무르기 요청 중에도 시간이 흐른다. 일반·속기는 같은 시간제 사용자끼리 매칭한다.
- 온라인 클라이언트가 시간 종료 확인을 요청해도 서버가 다시 시간을 검증한다. version 조건과 트랜잭션으로 중복 결과 반영을 방지한다.
- 모든 대국 화면이 닫혀 있을 때에는 별도 백그라운드 스케줄러가 실행되지 않는다. 경과시간은 보존되며 재접속 시 시간패가 처리된다.
- 변경 전 대국은 `legacy` 시간제를 유지하며, 새 대국에만 새 시간제를 적용한다. 기보 응답에 `timeControl`을 포함한다.

검증: `node --experimental-strip-types --experimental-vm-modules --test tests/*.test.mjs`
